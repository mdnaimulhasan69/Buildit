UNIVERSITY PHOTOS (optional)

The home page shows pictures of Port City International University.
If you put your own files in this folder, the site uses them first:

  campus.jpg   the campus or the main building (a wide photo)
  cse.jpg      the CSE department, a lab or a class photo
  logo.png     the university logo

If a file is missing, the site tries the picture on the university website.
If that fails too, it shows a drawn picture, so the page never looks broken.
Use only photos you are allowed to use.
